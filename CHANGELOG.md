## [1.0.0] - 2026-11-12

### Added

- A checked list of 35 primary sources and open-source tools for AI governance, in nine sections.
- `data/resources.json` as the source of truth, with a generator for `README.md` and a `--check` mode.
- A link checker that separates broken links from sites that refuse automated requests, and a monthly workflow that runs it.
- Tests for the data rules, the generated README and repository hygiene.
- Community files, citation metadata and a Dependabot configuration.
